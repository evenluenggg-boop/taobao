# 本地网页后台

本目录存放最简单的本地网页后台首页。当前实现是纯静态页面，不依赖外部前端框架，也不读取真实业务数据。

## 文件说明

- `index.html`：本地后台首页，展示示例概览、店铺接入状态和常用模板入口。

## 本地运行

在仓库根目录执行：

```bash
python scripts/serve_admin.py
```

默认访问地址：<http://127.0.0.1:8000/>

## 安全约定

1. 页面只能展示示例、脱敏或已授权展示的数据。
2. 不要把 Cookie、Token、账号密码、客户个人信息、聊天记录或客服隐私写入 HTML。
3. 如后续改为动态后台，应继续优先读取本地已忽略目录或授权数据库，不要提交真实业务数据。
